# austral-project/.github

Files shared by all the repositories of the organization:

- `profile/README.md`: home page of the organization on GitHub;
- `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md`, `CODE_OF_CONDUCT.md`, issue and pull request templates: applied by default to every repository that does not have its own;
- `.github/workflows/bundle-ci.yml` and `bundle-release.yml`: workflows reused by every bundle.

Changing a file here changes it for all the bundles.
